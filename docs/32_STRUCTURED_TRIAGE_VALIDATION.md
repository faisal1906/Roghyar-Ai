# AI-03 structured triage validation

PDF sections 5–7 and 10 and Appendix A.2 define the assessment pipeline. This private bridge verifies the authoritative AI-02 owner, current revision, lifetime and assessment schema. The caller supplies the server-assigned assessment event UUID. Snapshot authenticity and freshness require trusted atomic custody as documented in AI-02.

A versioned vocabulary defines fact meaning, boolean or integer type, exact unit and numeric bounds, and explicit question-option mappings. No conversion or inference from identifier text is permitted. The review reference is metadata. Trusted server composition must verify publication and provenance before supplying the vocabulary. The shipped default is empty. Only direct and corrected reports enter BE-03, as reported evidence. Current values retain event and supersession references. Conflicts become unknown with null values. Unmapped answers and absent mentions never become negatives.

The private inference protocol receives one validated text event of up to 4,000 Unicode code points with its event UUID and optional EN/UR/PS hint. Its UTF-8 JSON response is limited to 8 KiB and 32 candidates. Each candidate carries fact, value, support state, source UUID, optional exact unit and optional half-open code-point span. Explicit negation is a proposed boolean false. Hypothetical, quoted, third-party and uncertain candidates carry null. Matching an event and span establishes traceability only. Validated model candidates never enter the signed-rule interpreter. Original language text is preserved without translation, with Roman and mixed-language quality pending AI-06 and QA-01.

An optional Appendix A.2 proposal uses the four PDF levels. SEE_DOCTOR displays as SEE A DOCTOR and HOME_CARE as HOME CARE. Condition, specialty and question IDs must be allowlisted, and summary text must exactly match a configured reviewed phrase of at most 160 characters. No generated prose is rendered. The five-question cap includes previously asked questions. Duplicate keys, nonfinite numbers, extra keys, unknown vocabulary and mismatched source references fail closed.

The signed BE-03/04 evaluation runs before inference. Reviewed emergency, urgent, and urgent with unresolved risk return the original decision and skip inference. Rule failures remain unavailable. Lower model proposals never authorize care. Higher proposals can only request review. No AI-01 category gates independent safety evaluation.

No inference transport is connected or configured. The adapter contract supports a three-second cooperative deadline and cancellation. Future integration needs a bounded TLS adapter with approved privacy, credentials, egress and retention. No route, store, migration, clinical write or frontend activation is added. Release depends on reviewed mappings and language evidence, QA-01, AI-06 and GD-01. Tests use synthetic data and internal evaluator doubles alongside existing signed-engine regressions.
